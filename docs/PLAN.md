План затверджено замовником. Цей текст уже враховує правки з [BRIEF.md](BRIEF.md), частини B і C. Детальні рішення та арт-дирекшн лежать у [../DECISIONS.md](../DECISIONS.md), поточний стан — у [../PROGRESS.md](../PROGRESS.md).

- **Інструменти:**

- **Пакетний менеджер:** npm.

## 2. Архітектура

1. **Безперервний простір.** Кожна система лежить на місці свого вузла у всесвіті. «Занурення» — це політ камери всередину вузла:
   - вузол перетворюється на ядро, мережа згасає, зорі лишаються для паралаксу;
   - змонтовані лише активна система й та, що прогрівається, решта демонтується з dispose;
   - точність глибини (near/far, масштаб) перевіряється окремо.
2. **Стан сцени з URL.** Чиста функція `routeToSceneState(pathname)` у `src/lib/route-state.ts` повертає стан сцени.
   - `CameraDirector` реагує на зміну стану.
   - Користувацький ввід обробляє drei `CameraControls`: інерція, обмеження, touch.
   - Програмні польоти робить GSAP: 1,4–1,8 с, easing, FOV-punch і спалах bloom; політ переривається вводом користувача.
3. **Один HTML-контент для всіх режимів.** Кожна сторінка рендерить семантичний SSR-контент.
   - У 3D-режимі це панелі поверх сцени, на мобільному — bottom sheet.
   - У простому режимі це звичайна 2D-сторінка.
4. **Доступність вузлів через справжні посилання.** SSR-навігація по категоріях і планетах проходиться Tab-ом.
   - Фокус або hover на посиланні підсвічує вузол у сцені.
   - Підписи в Canvas мають `aria-hidden`, щоб не дублювати озвучення.
5. **Контент як дані.** `content/*.ts` (структура й візуальна ДНК) валідується через zod.
   - Тексти лежать у `messages/<locale>/content.json`, UI-рядки — у `messages/<locale>/ui.json`.
   - Сцена отримує серіалізований маніфест, зібраний на сервері (`src/lib/scene-manifest.ts`).
   - Нові категорії, послуги й кейси додаються лише даними.
6. **Шейдери як TS-модулі** (`/* glsl */`) зі спільними фрагментами noise і fresnel.
7. **Рендер-цикл.**
   - У прихованій вкладці рендер зупиняється (`frameloop: never`).
   - `demand` вмикається, коли сцену повністю закрито, а також при reduced-motion.
   - Прогрів систем: почергово в `requestIdleCallback` після всесвіту, на `touchstart` по вузлу, на hover.
8. **i18n для статичного експорту.**
   - `localePrefix: 'always'`, `setRequestLocale`, без proxy.
   - `/` — статична сторінка з redirect на `/pl/`.
   - Слаги англійські й однакові для всіх мов.
   - Canvas живе в `[locale]/layout`, тому при зміні мови перемонтовується. Це прийнятно.
9. **Навігація між планетами.** Клік робить `push`. Стрілки й свайп між сусідніми планетами роблять `replace`. Esc працює як «назад» або веде на батьківський маршрут.
10. **Хостинг: GitHub Pages.**
    - Конфігурація: `output: 'export'`, `trailingSlash: true`, `images.unoptimized`.
    - `NEXT_PUBLIC_BASE_PATH` задає basePath і assetPrefix, `NEXT_PUBLIC_SITE_URL` — абсолютний URL сайту.
    - Деплой через GitHub Actions; `.nojekyll`; опційно CNAME.
11. **Бекенд у майбутньому.**
    - `LeadSubmitter`: зараз `TelegramLinkSubmitter`, пізніше `ApiSubmitter` з адресою з `NEXT_PUBLIC_API_URL`.
    - `analytics.track()` поки no-op.
    - Route handlers не використовуються.

## 3. Telegram

Перевірено на core.telegram.org/api/links.

- **Основне посилання:** `https://t.me/<username>?text=<draft>`.
  - Альтернатива `tg://resolve?domain=<username>&text=<draft>` нічого не робить, якщо застосунок не встановлено.
  - Текст стає чернеткою в полі вводу; відправляє людина.
- **Правила документації.**
  - Текст має бути валідним UTF-8, кодується через `encodeURIComponent`.
  - Якщо текст починається з `@`, додається пробіл.
  - Клієнт обрізає текст до `message_length_max`.
  - Власний бюджет довжини URL: спершу компактний формат, потім обрізання коментаря з «…».
- **Fallback.** Кнопки «Скопіювати текст» і «Відкрити чат» показуються завжди.
- **Формулювання** гендерно-нейтральні.
- **Обмеження.** Чернетка з'являється лише якщо акаунту студії можуть писати всі. Це треба зазначити в REPORT.

   - зорі, мережа вузлів з імпульсами, 5 категорій, вузли портфоліо й конфігуратора;
   - hover і фокус, HTML-лейбли, CameraControls, автоповорот;
   - політ і «занурення», bloom, прогрів;
   - Playwright-скріншоти й e2e.
3. **M3.** Ядра й планети за ДНК, орбіти, hover, панелі послуг, стрілки, свайп і Esc, «Додати до запиту», dispose.
4. **M4.** Конфігуратор (7 кроків, zod, localStorage, передзаповнення, реакція сцени), генератор повідомлення, `TelegramLinkSubmitter` і fallback, тести.
5. **M5.** Портфоліо: скупчення-обсерваторія, фільтр, сторінка кейсу, три типи демо, статуси draft і published, стан «coming soon».
6. **M6.** Мобільні й продуктивність:
   - bottom sheet, hit-зони, рівні якості, AdaptiveDpr, DPR не більше 2;
   - простий режим із перемикачем і автоматичним увімкненням без WebGL;
   - reduced-motion, інтро до 3 с лише при першому візиті, екран завантаження;
   - виміри та рішення щодо відкладеного 3D.
7. **M7.** SEO (метадані, OG, hreflang), полішинг, README, повний аудит, REPORT.md. Ambient-звук — опційно.
